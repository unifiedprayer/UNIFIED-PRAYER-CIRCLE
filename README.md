# Unified Prayer Circle

Welcome to the official GitHub repository for **Unified Prayer Circle**, a faith-based initiative led by **Apostle Sabrina Clay**. This project exists to empower, equip, and encourage believers through prayer, peace, and purpose.

## 🌟 Mission

To create and share spiritually grounded digital resources that help individuals and ministries grow deeper in their relationship with God through the power of unified prayer.

---

## 📂 What’s Inside

This repository contains:

- 📖 **Devotionals** – Scripturally rooted reflections for personal or group study
- 🧎🏽‍♀️ **Prayer Declarations** – Faith-filled declarations based on Bible verses
- 📊 **Teaching Slides** – Visual materials for use in faith-based teaching settings
- 📱 **Social Media Graphics** – Ready-to-use Scripture images and encouragement posts
- 🖥️ **Website Code (HTML/CSS/JS)** – For landing pages and resource access
